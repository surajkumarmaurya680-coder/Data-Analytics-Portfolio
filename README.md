# Retail Sales Analysis using Python

## Project Description

This project analyzes retail sales data using basic Python.

## Analysis Performed

- Total Sales
- Total Quantity
- Product-wise Sales
- City-wise Sales
- Category-wise Sales
- Top Revenue Product
- Top Quantity Product
- Average Sales

## Technologies Used

- Python
- Lists
- Dictionaries
- For Loop
- If-Else
- Basic Python
